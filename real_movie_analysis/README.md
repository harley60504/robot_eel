# Real Movie Analysis Scripts

This folder keeps only the analysis code for real robot videos. Raw videos, recordings, CSVs, generated figures, and dated analysis output folders are ignored by Git.

## Setup

Run commands from the repository root:

```powershell
cd C:\Users\ytyla\Documents\GitHub\robot_eel
```

Install the Python packages used by these scripts if needed:

```powershell
pip install opencv-python numpy matplotlib
```

The default input video folder is `real_movie/`. Generated analysis folders should stay under `real_movie_analysis/`; those outputs are ignored by Git.

## Typical Workflow

1. Track the red LED marker in the real videos:

```powershell
python real_movie_analysis\analyze_red_dot_videos.py --video-dir real_movie --out-dir real_movie_analysis\2026-07-08
```

2. Aggregate measured trial metrics across one or more analysis folders:

```powershell
python real_movie_analysis\aggregate_real_trials_per_lap.py real_movie_analysis\2026-07-08 --out-dir real_movie_analysis\2026-07-08_summary
```

3. Draw trajectory or posture figures from the generated analysis folder:

```powershell
python real_movie_analysis\draw_time_colored_fitted_trajectories.py real_movie_analysis\2026-07-08
python real_movie_analysis\draw_relative_pose_figures.py real_movie_analysis\2026-07-08
python real_movie_analysis\draw_relative_pose_adaptive.py real_movie_analysis\2026-07-08 --video-root real_movie
```

## Script Reference

### `analyze_red_dot_videos.py`

Tracks the red marker in each `.mp4`, fits straight or turning metrics, and writes per-video analysis outputs.

Common command:

```powershell
python real_movie_analysis\analyze_red_dot_videos.py --video-dir real_movie --out-dir real_movie_analysis\2026-07-08
```

Useful options:

- `--videos name1 name2`: process only specific video filenames or stems.
- `--sample-count 5`: number of representative frames to export.
- `--max-seconds 15`: analyze only the first N seconds.
- `--px-per-m 269.2105609870623`: pixel-to-meter calibration scale.
- `--straight-start-seconds 4 --straight-seconds 12`: measurement window for straight swimming.
- `--turn-start-seconds 2 --turn-trim-last-seconds 3`: measurement window for turning.

Main outputs:

- Per-video folder with `summary.json`, `red_dot_tracking.csv`, representative frames, trajectory plot, and fit overlay video.
- Top-level `summary.csv`, `summary.json`, and `command_error_summary.csv`.

### `aggregate_real_trials_per_lap.py`

Reads per-video `summary.json` files and averages unique trials by condition.

```powershell
python real_movie_analysis\aggregate_real_trials_per_lap.py real_movie_analysis\2026-07-08 --out-dir real_movie_analysis\2026-07-08_summary
```

You can pass multiple roots:

```powershell
python real_movie_analysis\aggregate_real_trials_per_lap.py real_movie_analysis\2026-07-02 real_movie_analysis\2026-07-03 --out-dir real_movie_analysis\combined_summary
```

Outputs:

- `trial_metrics.csv`
- `condition_summary.csv`
- `condition_summary.json`

### `draw_time_colored_fitted_trajectories.py`

Draws time-colored trajectories with fitted circles or straight-line fits.

```powershell
python real_movie_analysis\draw_time_colored_fitted_trajectories.py real_movie_analysis\2026-07-08
```

Optional:

```powershell
python real_movie_analysis\draw_time_colored_fitted_trajectories.py real_movie_analysis\2026-07-08 --out-dir real_movie_analysis\2026-07-08_time_plots
```

Outputs individual plots plus a selected 9-panel montage.

### `draw_relative_pose_figures.py`

Draws real LED posture figures using the representative clean frames generated by `analyze_red_dot_videos.py`.

```powershell
python real_movie_analysis\draw_relative_pose_figures.py real_movie_analysis\2026-07-08
```

Useful options:

- `--out-dir PATH`: custom output folder.
- `--sample-count 5`: how many representative frames to use.
- `--max-poses 5`: max eel poses drawn per video.
- `--prefix LABEL`: contact-sheet filename prefix.

### `draw_relative_pose_adaptive.py`

Draws adaptive posture figures directly against the original videos and analysis outputs. Use this when you want the more polished teal/red adaptive figure style.

```powershell
python real_movie_analysis\draw_relative_pose_adaptive.py real_movie_analysis\2026-07-08 --video-root real_movie
```

Useful options:

- `--out-dir PATH`: custom output folder.
- `--label LABEL`: contact-sheet filename prefix.
- `--title-prefix TEXT`: prefix before each video title.
- `--px-per-m VALUE`: calibration scale override.

## Notes

- The scripts infer command type from filenames, such as `targetv17`, `turn_left`, `r03`, or `y05`.
- Keep raw videos in `real_movie/` and backend recording logs in `Release/python_backend/recordings/`; both are ignored by Git.
- Keep generated analysis outputs under `real_movie_analysis/`; only the root-level `.py` files and this README are meant to be committed.
